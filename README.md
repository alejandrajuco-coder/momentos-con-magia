# Momentos con Magia - pagina web

Pagina de ventas de videos de invitacion personalizados.

- `index.html`: la pagina (abre este archivo en el navegador).
- `assets/`: videos de muestra, logo, portada e imagenes de la pagina.

Para publicarla sin la barra de Muse: sube esta carpeta a Netlify Drop
(https://app.netlify.com/drop) o importa el repositorio en Lovable.
